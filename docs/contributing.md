# Contributing

See the repository's [CONTRIBUTING.md](https://github.com/rahulsharmaah/local-db-mcp/blob/main/CONTRIBUTING.md) for the full contributor guide.

The short version:

- Keep read-only behavior as the default.
- Do not expose credentials in tool responses.
- Add documentation for every new tool or config key.
- Use least-surprise APIs and clear error messages.
- Run compile and documentation checks before opening a pull request.
