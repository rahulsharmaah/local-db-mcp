# Code of Conduct

This project follows the Contributor Covenant Code of Conduct.

## Our Standards

Examples of behavior that contributes to a positive environment:

- Being respectful and constructive
- Accepting feedback gracefully
- Focusing on what is best for the project and its users
- Helping contributors learn the safety model before expanding capabilities

Unacceptable behavior includes harassment, personal attacks, publishing private information, or intentionally weakening safety controls without discussion.

## Enforcement

Maintainers may remove comments, reject contributions, or restrict participation when behavior is harmful to the project or community.
